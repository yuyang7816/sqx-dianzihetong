# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要第一个启动的。代码在 `server` 文件夹。数据库脚本在仓库根目录：`db/dianzihetong.sql`（**表结构 + 菜单权限 + 演示管理员**）。

## 开始之前要准备什么

在自己的电脑上安装下面软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 终端输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 5.7 或 8.0 | 能连上本机 MySQL，端口一般是 **3306** |
| Redis | 可选 | 当前 `application.yml` 里 `spring.redis.open` 为 **false**，本地可不启 |
| LibreOffice | 可选（合同转 PDF 需要） | `application.yml` 里 `jodconverter.local.office-home` 指到本机安装目录 |

Java 不要装成 11、17 或 21。装错版本时，先卸掉，再装 1.8。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

Maven 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的终端，再打开一个新的，`mvn -v` 才能看到版本。

MySQL 安装过程中会让你给 `root` 设一个密码，还会让你确认端口。把密码和端口记下来。

若以后打开 Redis（把 `spring.redis.open` 改为 `true`），需先启动 Redis。默认地址 `localhost:6379`，密码为空（与开源包 `application.yml` 一致）。

## 第 1 步：新建空数据库

这份 SQL 文件不会自己创建名叫 `dianzihetong` 的库。要先建库，再导入。

1. 打开 MySQL 命令行或客户端，登录。
2. 执行：

```sql
CREATE DATABASE IF NOT EXISTS dianzihetong DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

3. 再执行：

```sql
SHOW DATABASES;
```

列表里有 `dianzihetong` 就成功了。

如果提示 `Access denied`，是密码错了，用安装 MySQL 时设的那个密码重来。

## 第 2 步：导入项目里的数据库文件

文件位置（相对整个项目文件夹）：

`db/dianzihetong.sql`

导入会覆盖同名的表，所以请导入到上一步新建的空库，不要导入到别的业务库。

### macOS / Linux 示例

把密码、端口改成你的 MySQL：

```bash
mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 dianzihetong < db/dianzihetong.sql
```

### Windows PowerShell 示例

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 dianzihetong -e "source $($PWD.Path -replace '\\','/')/db/dianzihetong.sql"
```

执行结束时没有 `ERROR`，再执行下面这句，能看到很多表名（含 `contract`、`enterprise`、`sys_user`、`sys_menu` 等），就说明导入成功：

```bash
mysql -uroot -p你的密码 -P3306 -e "USE dianzihetong; SHOW TABLES;"
```

用 Navicat 也可以：连接到本机 MySQL，双击打开 `dianzihetong`，菜单选「运行 SQL 文件」，选中 `db/dianzihetong.sql`，编码选 UTF-8，点开始。

## 第 3 步：确认演示管理员

开源 SQL 已写入演示管理员：

| 项目 | 值 |
|---|---|
| 账号 | `admin` |
| 密码 | `admin123` |
| 角色 | 超级管理员（含全部菜单） |

上线前请立刻修改密码，不要把默认口令暴露在公网。

可在库里确认：

```sql
SELECT user_id, username, status FROM sys_user;
SELECT menu_id, name, url FROM sys_menu WHERE type = 1 LIMIT 20;
```

## 第 4 步：改数据库账号密码

打开：

`server/src/main/resources/application-dev.yml`

找到类似下面几行（开源包默认是本机占位）：

```yaml
url: jdbc:mysql://127.0.0.1:3306/dianzihetong?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=CTT&allowPublicKeyRetrieval=true
username: root
password: root
```

把 `username`、`password` 改成你的 MySQL 账号密码；端口不是 3306 时一并改 URL。库名保持 `dianzihetong`。

`application.yml` 里：

```yaml
spring:
  profiles:
    active: dev
```

本地联调保持 `dev`。部署到服务器时再切 `prod`，并改好 `application-prod.yml`。

建议同时修改 `application.yml` 里的 `sqx.jwt.secret`，不要使用仓库默认值上线。

合同转 PDF 若要用 LibreOffice，把 `jodconverter.local.office-home` 改成你机器上的真实路径（macOS / Linux / Windows 安装目录不同）。暂时不做转换时，可先忽略相关报错。

`server/ilb` 下若有本地 jar，按 `server/README.md` 里的 `mvn install:install-file` 说明安装到本地仓库后再编译。

## 第 5 步：启动服务端

在项目根目录打开终端：

```bash
cd server
mvn spring-boot:run
```

也可以用 IDEA：打开 `server`，找到 `com.sqx.SqxApplication`，右键 Run。

成功标志：控制台出现类似：

```text
电子合同项目启动成功
```

默认地址：

- 接口根路径：`http://localhost:9131/sqx_fast`
- Swagger（若已启用）：`http://localhost:9131/sqx_fast/swagger-ui.html`

这个窗口不要关。关掉就等于服务停了，管理端和用户端都会连不上。

## 第 6 步：验证是否就绪

浏览器打开管理端登录页要用的验证码接口是否通，可先访问：

`http://localhost:9131/sqx_fast/swagger-ui.html`

能看到接口列表更好。如果这个页面打不开，只要启动日志里有「电子合同项目启动成功」，并且接下来管理端能打开登录页上的验证码图片，也算服务端已经就绪。

短信、微信、支付宝、图片存储这些密钥需要自己到对应官网申请，再填进管理端「系统配置」等页面（写入 `common_info` / `sys_config`）。申请入口写在 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**`Access denied for user`**  
MySQL 密码和 yml 里的 `password` 不一致。把 yml 里的密码改成你安装时设的密码。

**`Unknown database 'dianzihetong'`**  
库还没建，或建错名字。回到第 1 步。

**端口被占用**  
改 `application.yml` 里的 `server.port`，同时把管理端代理、用户端 `common/config.js` 改成同一端口。

**依赖下载失败**  
检查网络或 Maven 镜像（可用阿里云中央仓库镜像），再执行 `mvn -U clean package`。

**LibreOffice / jodconverter 报错**  
本机未安装或 `office-home` 路径不对。先把路径改对，或暂时关闭文档转换相关功能后再测登录与基础接口。
