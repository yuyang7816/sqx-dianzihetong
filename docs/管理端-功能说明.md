# 管理端功能说明

管理端是给平台工作人员用的网站，在电脑浏览器里打开。合同签署方不使用这个网站。它用来管用户与企业认证、合同与模板、签署套餐与财务，以及填写微信、支付、短信、图片存储这些外面服务的账号。

程序里的名称是「省钱兄电子合同系统」。工作人员登录后，左侧是菜单。能看到哪些菜单，由该账号关联的角色与 `sys_menu` 数据决定。没有权限的菜单不会出现。开源 SQL 已包含菜单与超级管理员演示账号。

## 数据中心

首页看板，查看平台概览数据（以实际页面接口为准）。

## 用户中心

注册用户列表：查看详情、调整状态 / 积分或余额类字段、设置会员等（以页面按钮权限为准）。

## 财务中心

资金流水、退款 / 转账相关操作。是否自动打款取决于你是否另行对接支付侧；默认以后台记录与人工处理为主。

## 消息 / 注销

站内消息推送；用户注销申请的查看与处理。

## 首页装修

Banner 等运营位配置。

## 企业审核 / 个人审核

企业资质、个人实名资料的通过、拒绝、修改、封禁等。

## 订单中心

套餐 / 会员等相关订单查看与退款操作（以页面为准）。

## 模板管理

合同模板的增删改查，供用户端发起合同时选用。

## 合同套餐管理

签署次数套餐的价格与次数配置。

## 合同管理 / 印章管理

平台侧查看合同、印章相关数据与审核类操作。

## 充值配置 / 会员管理

充值档位、会员特权等。

## 帮助中心

帮助分类与文案，用户端「帮助」读取这些内容。

## 系统配置

平台通用配置项（短信、OSS、微信、支付宝、客服、协议、合同编号前缀、过期天数等，对应 `common_info` / `sys_config`）。改完要保存。用户端下次请求才会用新的密钥。

## 系统管理

管理员、角色、菜单。可继续细分按钮级权限。开源演示账号 `admin` 绑定超级管理员，可见全部菜单。

## 和用户端的关系

- 用户在 App / 小程序里发起合同、认证、买套餐；管理端审核与配置规则。
- 外面的密钥只配在后台配置页。用户端没有地方填写微信支付商户号。
