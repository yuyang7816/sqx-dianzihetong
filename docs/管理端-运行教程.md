# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `admin` 文件夹。程序名称是「省钱兄电子合同系统」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「电子合同项目启动成功」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

| 软件 | 用什么版本 | 怎样确认 |
|---|---|---|
| Node.js | **18**（推荐） | `node -v` 能看到 `v18` |
| npm | 随 Node 自带 | `npm -v` |

Node 17+ 跑旧版 Webpack 时需要 OpenSSL 旧算法。本项目 `npm run dev` 已带 `NODE_OPTIONS=--openssl-legacy-provider`。若在 Windows CMD 下该写法无效，可先执行：

```bat
set NODE_OPTIONS=--openssl-legacy-provider
npm run dev
```

## 第 1 步：确认接口地址

开发时 `admin/src/utils/httpRequest.js` 请求前缀是 `/sqx_fast/`，由 `admin/config/index.js` 代理到本机服务端：

```js
target: 'http://127.0.0.1:9131/sqx_fast/',
```

服务端端口若不是 `9131`，这里要一起改。  
`static/config/index.js` 里的 `baseUrl` 默认也是 `http://localhost:9131/sqx_fast`，打包部署时再改成你的域名。

## 第 2 步：安装依赖并启动

```bash
cd admin
npm install
npm run dev
```

成功后终端会提示本地地址，一般是：

`http://localhost:8001`

浏览器打开这个地址，应看到登录页。

## 第 3 步：登录

演示账号（开源 SQL 已写入）：

| 项目 | 值 |
|---|---|
| 账号 | `admin` |
| 密码 | `admin123` |

先点验证码图片，确认能显示（说明已连上服务端），再登录。

登录成功后，左侧应出现菜单，例如：数据中心、用户中心、财务中心、合同管理、模板管理、企业审核、个人审核、系统配置、系统管理等。若菜单为空，说明 `sys_menu` / `sys_role_menu` / `sys_user_role` 未正确导入，请重新导入 `db/dianzihetong.sql`。

## 第 4 步：建议先做的配置

1. **改掉演示密码**：右上角改密，或「系统管理 → 管理员列表」。
2. **系统配置**：短信、微信、支付宝、OSS、协议文案等。密钥未配时，用户端验证码、支付、云上传会失败。
3. **签署套餐 / 合同类型**：按业务需要维护，用户端购买与发起才会有数据。

## 常见问题

**验证码裂图 / 登录一直失败**  
服务端没启动，或代理端口不是 `9131`。先看服务端窗口是否还有「电子合同项目启动成功」。

**`error:0308010C:digital envelope routines::unsupported`**  
Node 版本偏新。确认使用了带 `--openssl-legacy-provider` 的启动命令，或改用 Node 16。

**左侧菜单是空的**  
重新导入带菜单数据的 `db/dianzihetong.sql`，确认 `admin` 用户已绑定「超级管理员」角色，再重新登录。

**接口 404**  
检查代理 `target`、服务端 `context-path`（`/sqx_fast`）是否一致。
