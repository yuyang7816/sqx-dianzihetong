# 用户端功能说明

用户端是个人 / 企业用户在手机或电脑网页里打开的那个应用。窗口标题是「电子合同」。底部一直有四个入口：**首页、合同管理、全部合同、我的**。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信这些外面的服务。

## 首页

入口聚合：发起合同、常用模板、认证引导、会员 / 套餐入口、客服等（以实际页面为准）。未登录时部分操作会跳到登录页。

## 合同管理

待我签、待他人签、抄送我的、已完成等待办视角。点进详情可查看文件、签署或拒签。

## 全部合同

按条件筛选自己相关的合同列表，进入详情继续处理。

## 发起与签署（分包页面）

- **选模板 / 上传文件**：填写合同字段，指定签署方、抄送方、截止日期。
- **签署**：手写签名或盖章；企业场景需已完成企业认证并有可用印章。
- **抄送 / 提醒**：依赖短信或站内消息；短信密钥未配时提醒发不出去。

## 企业与印章

- **企业认证**：提交企业资料，等管理端审核（或按后台配置自动通过）。
- **企业成员**：加入 / 管理企业空间（以页面为准）。
- **印章**：制作个人章或企业章，签署时选用。

## 会员 / 签署套餐

购买签署次数或会员权益。支付方式常见：

- **余额**：若页面提供该入口，扣钱包余额。
- **微信支付**：拉起微信支付。需要商户号、密钥，以及小程序或公众号 AppId。
- **支付宝**：同样要在管理端配好应用与密钥。

付成功后，微信或支付宝会通知服务端，订单才会变成已支付。付完钱立刻关页面、通知还没到时，订单可能要等一会儿才变。

## 我的

- **登录 / 注册 / 改密**：手机号 + 短信；或微信授权登录（小程序场景更常见，需 AppId）。
- **实名认证**：个人认证资料提交与进度。
- **帮助中心 / 协议 / 关于我们**：文案来自管理端配置。
- **设置 / 注销**：账号安全与注销申请。

## 外面服务对照

短信、微信、支付宝、图片存储的密钥填在管理端配置中，由服务端去调用。只改用户端页面上的字，不会变成已经开通。

| 功能 | 需要什么 | 申请入口 | 配在哪里 | 没配时的现象 |
|---|---|---|---|---|
| 注册、登录、改手机号、签署提醒等 | 短信服务商（阿里云 / 腾讯云等） | https://cloud.tencent.com/product/sms 、 https://www.aliyun.com/product/sms | 管理端配置 | 验证码发不出去 |
| 微信支付 | 微信支付商户平台 | https://pay.weixin.qq.com/ | 管理端相关配置 | 无法拉起微信支付 |
| 微信支付还要小程序或公众号 AppId | 微信公众平台 | https://mp.weixin.qq.com/ | 管理端微信配置 + `manifest.json` / `queue.js` | 只有商户号时仍然付不了 |
| 支付宝付款 | 支付宝开放平台 | https://open.alipay.com/ | 管理端相关配置 | 无法拉起支付宝 |
| 头像、合同文件、印章图上传 | 阿里云 OSS 等（或本地磁盘） | https://www.aliyun.com/product/oss | 管理端配置 | 上传失败或只能走本地路径 |
| 企业工商信息查询（可选） | 云市场企业查询类 API | 各云厂商市场 | 管理端相关配置项 | 企业信息自动填充失败，可改人工录入 |
