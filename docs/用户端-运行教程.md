# 用户端运行教程

按顺序做。这是给手机和网页用的应用，窗口标题是「电子合同」。用 HBuilderX 打开 `user` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `db/dianzihetong.sql` 并启动服务端。合同列表、认证状态等数据来自这个库。服务端没启动时，页面也许能打开，但接口会失败。开源 SQL 不含演示业务合同，首页 / 合同列表一开始可能是空的，需要先注册用户并在管理端配好基础配置。

## 开始之前要准备什么

安装 **HBuilderX** 正式版：https://www.dcloud.io/hbuilderx.html

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：改接口地址

打开：

`user/common/config.js`

开源默认是：

```js
const ROOTPATH = "http://localhost:9131/sqx_fast";
```

服务端端口或路径改过时，这里必须一致。真机预览不要用 `localhost`，改成电脑局域网 IP，例如 `http://192.168.1.8:9131/sqx_fast`。

微信小程序 AppId：

- `user/manifest.json` → `mp-weixin.appid`（默认空）
- `user/common/queue.js` → `getWxAppid()`（默认空字符串）

自己练习时填入你的小程序 AppId，或继续只用浏览器运行。

## 第 2 步：用 HBuilderX 打开项目

HBuilderX → 文件 → 打开目录 → 选中仓库里的 `user` 文件夹。

## 第 3 步：运行到浏览器

菜单「运行」→「运行到浏览器」→ Chrome（或系统默认浏览器）。

成功标志：浏览器打开后能看到底部四个入口（首页、合同管理、全部合同、我的）。点「我的」进登录 / 注册。

## 第 4 步：在微信小程序里运行（可选）

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里 `mp-weixin` → `appid` 为空或不是你的号码时，微信会提示 AppID 没有权限。自己练习时，把这个 `appid` 改成你自己的小程序 AppID，并同步 `common/queue.js`，或继续只用浏览器运行。

微信开发者工具里如果提示域名不合法，本地调试可以勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

## 第 5 步：注册与基础联调

库里没有合同数据时，列表是空的。这表示接口可能已经通了，只是还没有数据。用手机号注册需要短信；短信密钥没配时，验证码发不出去。密钥申请见 [用户端功能说明](用户端-功能说明.md) 末尾。

可先在管理端确认系统配置、合同类型、签署套餐已有基础数据，再回用户端发起一份合同做联调。

## 常见问题

**列表一直转圈或提示网络错误**  
服务端没有启动，或 `common/config.js` 端口 / 路径不对。先看服务端窗口是否还有「电子合同项目启动成功」，再确认第 1 步为 **9131**，然后重新运行到浏览器。

**收不到短信验证码**  
管理端尚未配置短信密钥，或短信签名 / 模板未过审。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。

**上传文件失败**  
默认按本地上传思路配置。若改成 OSS，需在管理端配好密钥与 Bucket；本机还要保证服务端上传目录可写。
